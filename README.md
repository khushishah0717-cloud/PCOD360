# PCOD360
An intelligent web-based system for early PCOD risk assessment, menstrual tracking, and health guidance using machine learning.

## Features
- Early PCOD risk assessment
- Machine learning-based risk classification
- Menstrual cycle tracking and next-period prediction
- PCOD-focused health guidance chatbot
- User data management

## Technologies Used
- PHP
- MySQL
- JavaScript
- HTML5
- CSS3
- PHP-ML
- Composer

## Machine Learning
PCOD360 uses a Support Vector Classifier (SVC) with a linear kernel to classify users into four risk levels:
- None
- Low
- Moderate
- High

## Project Structure
- `pages/` – Website pages
- `api/` – Backend processing
- `ml/` – Machine learning files
- `assets/` – Website assets
- `config/` – Database configuration

## Disclaimer
PCOD360 is an academic research project designed for early risk assessment, awareness, and monitoring. It is not intended to provide medical diagnosis or replace professional medical advice.
